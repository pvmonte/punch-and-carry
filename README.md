# Punch And Carry
## Objective
This repository is an example of mobile game mechanic. The objective of the game is to beat the enemies to knock them down, pick up them and, then, drop them on a Sell Point to Earn money. The money can be used to buy a level up. The build should run with 30 fps on old fones or 60 fps on new fones.

## Restriction
When the Enemy is punched it turns on a Ragdoll
The project is made on Unity 6 and uses Awaitables instead of Coroutines.
No 3rd-party code is used. Some codes could be cleaned by using a DI framewirk like zenject, but, since the project doesn't use 3rd-party code I didn't use them,
The project prioritize code organization over performance since it still reaches the desired fps.
